This project has been provided based on Demo purposes, the real-life data do not exist within the repository for confidentiality purposes.
Therefore Regulation.Sample.JSON is only consisted of very limited data chunks.
Before running this project make sure to have Ollama and "qwen2.5:7b" within it installed.

The code samples below are run locally, to test the technical performance of the named files here, replace the path with the path you have saved the models within:
test_qwen.py 
test_embedding.py
test_logic.py

The code files beneath help to make sure the models have been saved in the right directory:
savingModel.py
Finding Model with HF Directory.py

Please do note that if you have saved the files and model folders within the same directory as your existing directory, no need to run these.

The model prototype is run with: 
Cmd Chatbot Prototype.py

Saving the data within vector database:
SavingData.py

Running the User Interface:
ui.py

The feedback logs are saved in: 
Feedback_Log.xlsx
